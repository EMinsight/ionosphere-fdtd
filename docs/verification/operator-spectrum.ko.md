# 이산 구면 연산자 스펙트럼

[English original](operator-spectrum.md)

## 목적

Stage 3은 FDTD metric factor가 유도하는 circumcentric primal/dual scalar Laplacian에서 수평 수치 분산을 직접 측정한다. 기존 `l=1,2` 검사를 `l=100`까지 확장하고, native polar 격자와 Mesquite 최적화 격자를 subdivision 6, 7, 8에서 비교한다.

## 물리적인 degree 범위

수평으로 전파하는 ELF 모드에서는 다음 관계를 쓸 수 있다.

```text
l ~= beta R = 2*pi*f*R / v(f)
```

전파 검증과 같은 Bannister 위상속도를 사용하면 50 Hz에서 `l=8.55785`, 500 Hz에서 `l=75.5659`를 얻는다. 따라서 평가 범위 `l=1–100`은 물리적 대역 전체를 포함하며, 해상도 부족이 시작되는 구간도 그 위에서 확인할 수 있다.

각 degree에서 real `Y_l^0`, real `Y_l^l`, imaginary `Y_l^l`을 평가했다. 면적 가중 Rayleigh 유효 고유값, 유효 wavenumber, 적합한 고유값을 제거한 뒤의 잔차를 기록했다. 이 zonal 및 sectoral 모드는 서로 다른 방향을 표본화하지만 `2l+1`개 order 전체를 열거하지는 않는다.

평균 wavenumber 오차는 관련 범위 전체에서 음수이며 degree가 커질수록 매끄럽게 증가한다. `l=9–75`에서 평균한 native 수렴 차수는 subdivision 6→7에서 1.988, 7→8에서 1.997이다. 상단 ELF 범위의 level 7→8 차수는 1.993이다. Mesquite도 0.001 이내에서 같은 차수를 보인다.

Mesquite는 고유함수 일관성을 크게 개선하지만 Rayleigh 고유값은 개선하지 않는다. `l=76`에서 level-8 잔차는 0.1522%에서 0.0362%로 감소하지만 wavenumber 오차는 −0.4122%에서 −0.4135%로 바뀐다. 국소·정적 일관성과 분산을 결정하는 고유값이 서로 다른 반응을 보인다.

Native subdivision-8 scalar wavenumber 오차와 Stage 1 상대 위상속도 잔차는 공통 주파수 bin 45개에서 상관계수 0.856을 보인다. 크기를 비교하면 다음과 같다.

부호와 고주파 증가 형태가 일치하므로 상단 대역 불일치의 일부를 직접 수치적으로 설명한다. 그러나 scalar 연산자는 넓은 대역에 공통으로 나타나는 offset이나 전체 오차 크기를 설명하지 못하며, 약 300 Hz 아래에서 특히 차이가 크다.

## 판정 기준

수평 scalar 연산자 분산은 약 2차로 수렴하는 고주파 기여 요인으로 확인됐다. 하지만 3-D Maxwell 전파 잔차 전체를 설명하지는 못한다.

Mesquite도 이전과 같은 패턴을 재현한다. 정적 조화함수 일관성은 크게 개선하지만 관련 유효 wavenumber는 거의 바꾸지 않는다. 따라서 다음 연산자 수준 분석에서는 scalar Laplacian만으로 Maxwell 전파를 추론하지 말고 완전한 curl/Hodge Maxwell 고유값 문제를 다뤄야 한다. 순서대로 진행하는 검증 캠페인에서는 이번 결과를 바탕으로 독립 하부 경계 대조군인 Stage 4도 시작할 수 있다.
